# 兼容性与修改边界

真实原版样本：Bandizip 7.46.0.1，Windows x64。其他真实发行版本尚未验证。

分析器不读取版本号决定是否允许操作。测试还覆盖了修改版本资源、改变 PE ImageBase 和移动节文件偏移的合成样本；这些测试验证的是地址推导方式，不能代替其他真实发行版本测试。

当前仅支持 x64 原生 PE32+，要求全部必需功能唯一匹配。仅有部分匹配、已打其他补丁、混淆、架构不同或未来结构变化时，工具会拒绝应用。

识别使用 `/nosleep`、`/force`、`STATIC_WEB_AD1/2`、`LaunchPopupAdWindow`、`skin_ad.xml`、`txt%d`、`url%d` 等引用，并结合函数范围、Windows API 导入与指令结构验证。字符串本身不是充分条件；细节以 `src/Analyzer.cs` 为准。

工具仅处理已识别入口，不保证未知广告渠道被覆盖。不会修改系统 hosts、添加防火墙规则、安装服务或计划任务。四项 HKCU 设置修改会记录原有类型和值；恢复要求原操作用户。目标文件变动后拒绝以旧计划或不一致备份覆盖。

如扫描失败，请提供脱敏日志，保留原文件与备份。不要强行套用旧偏移，也不要将原程序或备份提交到公开仓库。
